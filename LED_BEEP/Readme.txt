========================================================
LED_BEEP —— 跑马灯 + 蜂鸣器实验（含选做：PWM 呼吸灯）
========================================================
开发板：正点原子阿波罗 V2 STM32F429（STM32F429IGTx, LQFP176）
        配套 DNF429-EB 嵌入式实验箱（面包板 + 散装 LED/按键）

--------------------------------------------------------
一、硬件接线（8 个外接 LED + 4 个按键 + 蜂鸣器）
--------------------------------------------------------
【8 个 LED】低电平点亮，正极经 1K 限流电阻接 3.3V/5V，负极接引脚
    LED0 = PE10      LED1 = PE11      LED2 = PE12      LED3 = PE5
    LED4 = PE13      LED5 = PE7       LED6 = PE8       LED7 = PE9

【4 个按键】板载按键，无需额外接线
    KEY0   = PH3     低电平有效（内部上拉）
    KEY1   = PH2     低电平有效（内部上拉）
    KEY2   = PC13    低电平有效（内部上拉）
    KEY_UP = PA0     高电平有效（内部下拉）

【蜂鸣器】板载有源蜂鸣器，经 PCF8574(IIC IO 扩展芯片) 的 P0 驱动
    IIC 总线：SCL = PH4, SDA = PH5（板载 4.7K 上拉）
    器件地址：0x20（A2/A1/A0 全接地）
    驱动电路：S8550(PNP) 高边开关 -> P0 拉低时鸣响（低电平有效）
    实现文件：Src/pcf8574.c + Inc/pcf8574.h（软件模拟 IIC，约 100kHz）
    上电会"滴"一声（BEEP_BOOT_SELFTEST=1），用于验证整条链路
    依据：《阿波罗V2 硬件参考手册》2.1.14 与 2.1.24

--------------------------------------------------------
二、时钟配置
--------------------------------------------------------
    HSE = 25MHz（PH0/PH1 外部晶振）
    PLLM = 25, PLLN = 360, PLLP = 2  →  SYSCLK = 180MHz
    HCLK = 180MHz, APB1 = 45MHz, APB2 = 90MHz
    Over-Drive 模式 + 稳压器 Scale1 + Flash 5 等待周期
    调试接口：SWD（PA13/PA14）

--------------------------------------------------------
三、功能说明（对应实验要求）
--------------------------------------------------------
4 种跑马灯特效，由 4 个按键切换，每次按键蜂鸣器响一次（80ms）：

    KEY0   短按 →  特效0：单点移动（一个灯依次跑过 8 个位置）
    KEY1   短按 →  特效1：逐格点亮（1、2、3…8 个灯逐渐亮起，然后全灭）
    KEY2   短按 →  特效2：奇偶交替（奇数位灯与偶数位灯交替闪）
    KEY_UP 短按 →  特效3：全亮全灭（8 个灯一起闪）

【选做部分】呼吸灯：PWM 占空比渐变，亮度平滑变化

    KEY_UP 长按（>=600ms） → 进入 / 退出呼吸灯模式

    实现方式：TIM7 更新中断 + 软件 PWM
        中断频率 20kHz，一个 PWM 周期分 100 级 → PWM 频率 200Hz
        200Hz 远高于人眼闪烁融合频率，看不出闪烁，只看到亮度连续变化
        占空比按余弦曲线 0 -> 100 -> 0 变化，周期约 2.56s（64 级 × 40ms）
        8 个 LED 共用同一占空比、完全同步呼吸，接线无需任何改动

    为什么不用定时器的硬件 PWM 通道：
        8 个 LED 中 PE9/PE11/PE13 是 TIM1_CH1/CH2/CH3、PE5 是 TIM9_CH1，
        有独立的 PWM 输出通道；PE8/PE10/PE12 只能作 TIM1 的互补输出
        CH1N/CH2N/CH3N；而 PE7(LED5) 只有 TIM1_ETR —— 外部触发输入，
        根本没有输出通道。所以纯硬件 PWM 最多覆盖 7 个灯，无法让 8 个灯
        同步呼吸。软件 PWM 对引脚无任何外设要求，8 个灯可完全同步，
        而且一根线都不用改。

    与蜂鸣器互不干扰：
        蜂鸣器走 PH4/PH5 软件 IIC。IIC 是静态总线（没有最低时钟频率要求），
        被 20kHz 中断打断只会让 SCL/SDA 的保持时间变长，不会传输出错。
        另外 PWM 中断优先级设为 1（低于 SysTick 的 0），
        不影响 HAL_GetTick 的毫秒节拍，按键消抖与灯效计时都不受干扰。

按键处理特性：
    - 20ms 时间戳消抖，不阻塞主循环
    - KEY0~KEY2 与 KEY_UP 短按都只识别"按下边沿"，长按不会重复触发
    - KEY_UP 的短按动作等"松手"才判定，因此长按时不会先误切一次特效 3
    - 因此每次有效按下（含长按），蜂鸣器都只响一次

关键代码位置：
  Src/main.c
    led_pins[] / key_pins[]   : 引脚表（跑马灯与呼吸灯共用同一份）
    APP_GPIO_Init()           : 应用层 GPIO 初始化
    Key_Update_Debounce()     : 4 个按键的消抖，返回电平翻转掩码
    Scan_Effect_Key()         : 取出 KEY0~KEY2 的按下事件
    Scan_KeyUp_Gesture()      : KEY_UP 短按 / 长按手势识别
    Select_Effect()           : 切换特效 + 触发蜂鸣（会先退出呼吸灯模式）
    Run_Effect_Task()         : 4 种特效的图案表与推进
    Write_Leds()              : 位模式驱动 8 个 LED（非呼吸模式时）
    Breath_Init()             : 把 8 个 LED 登记给软件 PWM 模块
    Breath_Toggle()           : 进入 / 退出呼吸灯模式
    Run_Breath_Task()         : 余弦占空比表 + 亮度推进
    Buzzer_Beep()/Buzzer_Task(): 蜂鸣器单次发声与自动关断

  Src/softpwm.c + Inc/softpwm.h（软件 PWM 驱动，可复用）
    SoftPwm_Init()            : 登记通道 + 配置 TIM7 时基（20kHz）
    SoftPwm_SetDuty()         : 设置占空比 0..100（所有通道统一）
    SoftPwm_Enable()          : 启动 / 停止 PWM
    SoftPwm_ISR()             : 滴答处理，写 BSRR 输出
    TIM7_IRQHandler()         : 更新中断服务函数

六、注意事项（如需用 CubeMX 重新生成代码）
--------------------------------------------------------
    1. 根目录 Makefile 会被 CubeMX 覆盖，需要重新补上这一行：
           C_SOURCES += Src/softpwm.c
       （CubeIDE 的托管编译会自动扫描目录，不受影响）

    2. 若在 CubeMX 里也配置了 TIM7，它会在 Src/stm32f4xx_it.c 中生成
       一个同名的 TIM7_IRQHandler，与 softpwm.c 里的重复，链接会报
       "multiple definition"。届时删掉其中一个即可（建议保留 softpwm.c 的）。

    3. Src/softpwm.c 与 Inc/softpwm.h 不是 CubeMX 生成的文件，
       重新生成代码不会动它们。
