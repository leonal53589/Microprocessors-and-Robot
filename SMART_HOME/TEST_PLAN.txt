================================================================
 SMART_HOME 验收步骤与记录表 —— 智能家居中控终端（实验三）
================================================================
板卡：正点原子阿波罗 V2 STM32F429（STM32F429IGTx）+ DNF429-EB 实验箱
固件：build/SMART_HOME.elf（make all 产生，flash.bat 烧录）
外设：7 寸 800x480 RGB 屏（RGBLCD 接口）+ ATK-OV5640（P6）
      DHT11（PB12 单总线）+ 电压表 RV1（P10 跳线 -> PA5/ADC1_IN5）
【接线】不需要杜邦线：屏接 RGBLCD、摄像头插 P6、DHT11 对插单总线座、电压表
        靠 P10 跳线帽接通。详见 WIRING.txt。
【按键】K0(PH3)/UP(PA0) 切页；K1(PH2) 摄像头页重新初始化；K2(PC13) 立即测温湿度。
【双色灯】正常 绿常亮/红灭；越限 绿灭/红 2Hz 闪；故障 绿灭/红常亮（低电平点亮）。
【阈值】温度 30.0 ℃（回差 1.0）/湿度 70.0 %RH（回差 2.0）/电压 2.80 V（回差 0.05），
        都在 Inc/config.h。单项越限不好诱导时就把对应上限改到当前值以下再烧录。
----------------------------------------------------------------
 验收项 1 · 温湿度采集与错误状态
----------------------------------------------------------------
操作：1) 上电进中控首页；2) 看左侧两张卡片的温湿度数值；3) 按 K2 立即测一次；
      4) 对着 DHT11 哈气看湿度变化；5) 拔掉 DHT11（座子空着 / DQ 悬空）再按 K2
期望现象：
  - 正常：卡片显示 温度 xx ℃ / 湿度 xx %RH，右下 DHT11 行显示“正常”（绿）；
          按 K2 数值立即再更新一次，不必等 2.0s 周期；哈气后湿度上升再回落
  - 拔掉后：卡片变 “--” + 错误状态字；DHT11 行变“无应答”（红）；
            横幅变“数据故障”，红灯常亮、绿灯灭
判定：
  [ ] 温湿度量级与实际环境相符（室内约 20~30 ℃、40~70 %RH）
  [ ] 每 2.0s 自动刷新，K2 能立即再测一次
  [ ] 未接 / 断开传感器时【不显示旧数据】，而是 “--” + 错误状态字
  [ ] 错误状态能区分 无应答 / 超时 / 校验错 / 超量程
  [ ] 故障时红灯常亮、绿灯灭（与“越限”的闪烁明显不同）
  [ ] 故障判定是【一次读失败就进故障】（valid=0 直接判 FAULT），不是等连续 3 次
记录：室温 ______ ℃   湿度 ______ %RH   哈气后最高 ______ %RH
      断开后状态字：____________   进入故障延时 ______ s
----------------------------------------------------------------
 验收项 2 · 电子电压表（RV1 -> P10 -> PA5/ADC1_IN5）
----------------------------------------------------------------
操作：1) 确认 P10 跳线帽插好；2) 首页看换算电压（2 位小数），右下“电压表”
      一行看 【原始 ADC 值 -> 换算电压】；3) 把 RV1 拧到 低/中/高 三个位置，
      各停 10 秒并读数；4) 每个位置连读 5 次看波动，用万用表量同一点对比
期望现象：原始值 0~4095、换算电压 0.00~3.30 V，恒满足 V = raw x 3.3 / 4095
          （误差 <= 0.02 V）；同一位置停留时读数基本稳定
判定：
  [ ] 原始值与换算值【同时显示】（实验要求的硬指标）
  [ ] 转动 RV1 时电压连续变化，不卡死、不跳变
  [ ] 三个位置读数与万用表差值在 ±0.05 V 以内，且保留两位小数
  [ ] 同一位置 5 次读数波动 <= ±0.02 V（考验 16 次平均够不够）
记录表：
   位置  原始 ADC 值  屏上电压(V)  万用表(V)  差值(V)  5次波动
   ----  -----------  -----------  ---------  -------  --------
   低    __________   __________   ________   _______  ________
   中    __________   __________   ________   _______  ________
   高    __________   __________   ________   _______  ________
   分辨率：3.3 V / 4095 ≈ 0.806 mV/字

 验收项 3 · 中控首页与局部刷新（不闪）
----------------------------------------------------------------
操作：1) 上电进首页看整体布局；2) 按 K2 触发刷新，盯住三张卡片以外的区域
      （框线、标签、阈值面板）；3) 慢慢拧 RV1 让电压数字连续变化，同时观察
      屏幕其他部分；4) 用手机慢动作回放逐帧看刷新那一瞬间
期望现象：顶栏 = 实验名称 + 右侧报警状态；信息行 = 姓名/学号/班级（来自
          config.h）；三张卡片 = 标签 + 大号数值 + 单位；右上“预警阈值”三行；
          右下“模块状态”三行；底栏按键提示。【只有数值那一小块矩形在变】
判定：
  [ ] 实验名称、姓名、学号、班级正确显示（中文不乱码、不出方块）
  [ ] 温度/湿度/电压三项都有数值 + 单位
  [ ] 右上阈值面板显示的上限值与 config.h 一致
  [ ] 数值刷新时【不整屏闪烁】，静态部分（框线、标签）不重画
  [ ] 数值变化后【不留残影】（旧数字被完整覆盖）
  [ ] 底栏操作提示与实际按键功能一致
记录：屏上上限 温度 ______ ℃  湿度 ______ %RH  电压 ______ V
      与 config.h 一致：______   是否观察到整屏闪动：______
----------------------------------------------------------------
 验收项 4 · 阈值预警状态机（三种单项 + 一种多项 + 一次故障 + 回差）
----------------------------------------------------------------
4.1 电压单项越限（最容易做的一项）
操作：慢慢把 RV1 拧高直到超过 2.80 V；再把 RV1 拧回去
期望：红灯 2Hz 闪、绿灯灭；横幅变“越限报警”；阈值面板【只有】“电压上限”
      那一行标“越限”（红），温度/湿度两行仍“正常”
判定：[ ] 越限瞬间灯与文字同时变化（不是延迟几秒）
      [ ] 只有电压那一行标“越限”
      [ ] 红灯闪烁约 2Hz（2 秒内约 4 次亮灭）
      [ ] 拧回 2.75 V 以下后报警解除，绿灯恢复常亮
记录：电压越限起始 ______ V   解除 ______ V
4.2 温度单项越限
操作：把 config.h 的 CFG_TEMP_MAX_C 改成比室温低的值（如 20.0f）后重编烧录
期望：只有“温度上限”那一行标“越限”，灯按 2Hz 闪
判定：[ ] 只有温度那一行标“越限”，另两行仍“正常”
      [ ] 灯的行为与 4.1 一致；改回原值后报警解除（回差：要降到 上限-1.0）
记录：温度越限起始 ______ ℃   解除 ______ ℃（应低约 1.0）
4.3 湿度单项越限
操作：把 CFG_HUMI_MAX_PCT 改到比当前湿度低的值后重编烧录；或对着 DHT11
      连续哈气让湿度越限
期望：只有“湿度上限”那一行标“越限”
判定：[ ] 只有湿度那一行标“越限”
      [ ] 灯行为与 4.1 一致
记录：湿度越限起始 ______ %RH   解除 ______ %RH（应低约 2.0）
4.4 多项同时越限（至少做一种）
操作：先拧 RV1 让电压越限，再对着 DHT11 哈气让湿度也越限；或直接把
      CFG_TEMP_MAX_C 改 20.0f 且 CFG_VOLT_MAX_V 改 1.00f 后烧录
期望：两行（或三行）同时标“越限”；报警仍是“越限报警”（不能错变成
      “数据故障”）；灯仍是 2Hz 闪
判定：[ ] 多项越限时【每一行】都正确标记
      [ ] 报警状态没有从“越限”错变成“故障”
      [ ] 只恢复其中一项时报警仍保持（还有别的项越限）
      [ ] 全部恢复后才回到“系统正常”、绿灯常亮
记录：同时越限的项目：____________   全部恢复后是否回正常：______
4.5 一次传感器故障（必须与越限可区分）
操作：拔掉 DHT11（或拔掉 DQ 线），等一次采集周期（<= 2.0s）或按 K2
期望：横幅变“数据故障”；红灯【常亮】（不是闪）、绿灯灭；温度/湿度卡片变
      “--” + 错误状态字；DHT11 行显示“无应答”（红）
判定：[ ] 故障（常亮）与越限（2Hz 闪）明显可区分
      [ ] 故障优先：即使此时电压也越限，仍显示“数据故障”
      [ ] 不会把旧温湿度数据标成最新读数
      [ ] 插回传感器后能自动恢复（下一次采集成功即恢复）
      [ ] 恢复后越限标志被清零并按当前值重判（不带旧报警恢复）
记录：拔掉后进入故障延时 ______ s   插回后恢复延时 ______ s
4.6 回差行为（要能观察到）
操作：把 RV1 慢慢拧到刚好 2.80 V 附近，在 2.75~2.85 V 之间来回微调
期望：进入报警要 > 2.80 V，解除要 <= 2.75 V，中间一小段保持当前状态
判定：[ ] 在 2.75~2.80 V 之间来回时报警状态【不反复跳变】
      [ ] 进入/退出阈值与 config.h 的回差设置一致
记录：观察到报警开始跳变的区间 ______ V ~ ______ V
----------------------------------------------------------------
 验收项 5 · 摄像头预览与页面切换
----------------------------------------------------------------
操作：1) 断电插好 ATK-OV5640 到 P6 再上电；2) 首页按 K0 切到摄像头页；
      3) 手在镜头前晃动看是否实时，看右侧状态栏；4) 按 K1 重新初始化；
      5) 断电拔掉摄像头后上电，再切到摄像头页看提示；6) 按 K0 回首页再切回
期望现象：切换后先显示“摄像头初始化中 / OV5640 @ P6 (DCMI)”，随后出 640x480
          实时预览（QVGA 2 倍放大铺满左半屏），右侧状态栏显示温度/湿度/电压/
          预警状态/预览正常；拔掉后中央显示“摄像头初始化失败”或“无信号”并提示
          按 K1 重初始化（不是空白屏）
判定：
  [ ] 预览能出图，颜色基本正常（不是花屏/撕裂/错位）
  [ ] 画面实时（晃动有响应）
  [ ] 右侧状态栏数据正确
  [ ] 拔掉摄像头时显示明确提示，不是空白屏
  [ ] 按 K1 能重新初始化并恢复画面
  [ ] K0/UP 来回切换，每次都能正常出图
  [ ] 预览页【预警持续生效】（越限时红灯仍闪、状态栏显示报警字）
记录：首次出图耗时 ______ s   是否偏色（偏色则把 CFG_CAM_BYTE_SWAP 改 1）：______
      拔掉后显示的文字：____________   重插并按 K1 是否恢复：______
----------------------------------------------------------------
 验收项 6 · 集成验证（反复切页后数据仍在更新）
----------------------------------------------------------------
操作：1) 回首页记下当前温度/湿度/电压；2) 切到摄像头页停 30 秒；
      3) 切回首页看三项是否是这 30 秒内的【最新值】而不是切页前的旧值；
      4) 来回快速切换 10 次以上看是否卡死/花屏/黑屏/数据停更；
      5) 停在摄像头页 1 分钟看右侧数值是否仍在更新
期望现象：采集任务（DHT11 2.0s、ADC 200ms）与当前页面无关，切页照常进行；
          回首页立刻显示最新有效数据；切换不卡顿（主循环全程非阻塞）
判定：
  [ ] 摄像头页停留期间温湿度/电压仍在采集（切回是最新值）
  [ ] 停在摄像头页 1 分钟，右侧数值仍在更新、预警判断仍生效
  [ ] 反复切换 10 次以上不卡死、不花屏、不黑屏
  [ ] 全程按键响应及时（没有“卡住几秒”的感觉）
记录：切页前首页温度 ______ ℃ -> 切回后 ______ ℃（是否更新：______）
      快速切换 ______ 次，是否异常：________
----------------------------------------------------------------
 验收项 7 · 接线与供电安全（这一项是“查”，不是“测”）
----------------------------------------------------------------
  1) 电压表：P10 跳线帽插好；PA5 全程只接触 RV1 的 0~3.3 V
  2) 摄像头：插在 P6、方向正确；每次插拔都在断电状态
  3) DHT11：VCC 接 3.3 V（不是 5 V）、DQ 接 PB12、GND 接 GND
  4) 屏：接 RGBLCD 接口，方向正确，座子/排线无虚接
  5) 供电：实验箱标配电源，上电无火花、板子无异常发热
  6) 若用了杜邦线：确认没有把两个推挽输出脚直接相连
判定：
  [ ] PA5 全程只接触 0~3.3 V 范围
  [ ] 所有模块都是断电插拔，且 DHT11 用 3.3 V 供电
  [ ] 上电后无异常发热、无异味，不存在“两个输出脚对拉”的接法
  [ ] 屏、摄像头、DHT11 都插到底且方向正确

 附一 · 参数速查
================================================================
时钟：HSE 25 MHz -> PLLM=25 / PLLN=360 / PLLP=2 -> SYSCLK 180 MHz；HCLK 180 /
      APB1 45 / APB2 90 MHz；SDRAM SDCLK = HCLK/2 = 90 MHz；LTDC 像素时钟 30 MHz
LTDC：HSW 48 / HBP 88 / HFP 40 -> 行 976；VSW 3 / VBP 32 / VFP 13 -> 场 528
      帧率 = 30 MHz / (976 x 528) = 58.2 Hz；RGB565；帧缓冲 750 KiB @ 0xC0000000
SDRAM：W9825G6KH-6 32 MB，SDCLK 90 MHz，CAS=3
      刷新计数器 = (64ms / 8192 行) x 90MHz - 20 = 683
DMA：DMA2_Stream1_Channel1，P2M，Word/Word，Length = 320x240x2/4 = 38400 字
     （单位是“字”不是字节）；帧超时 400 ms，连续 3 次失败判故障
ADC：ADC1_IN5 = PA5，ADC 时钟 22.5 MHz，采样 480 周期，12 位，16 次平均
     1 LSB ≈ 0.806 mV（3.3 V / 4095）
DHT11：PB12，起始拉低 20 ms，判 1 阈值 45 us，超时 120 us，读取期间关中断；
       采样周期 2000 ms（2.0 s），与 config.h 的 CFG_DHT_PERIOD_MS = 2000 一致
阈值：温度 30.0 ℃ / 回差 1.0   湿度 70.0 %RH / 回差 2.0   电压 2.80 V / 回差 0.05
任务：DHT11 2000 ms / ADC 200 ms / 按键 10 ms / 界面 200 ms / 红灯翻转 250 ms
引脚：屏 = LTDC(AF14) + 背光 PB5；摄像头 = DCMI(AF13) + SCCB PB4/PB3 + RST PA15；
      DHT11 PB12；电压表 PA5；绿灯 PB0；红灯 PB1；按键 K0 PH3/K1 PH2/K2 PC13/UP PA0

 附二 · 常见问题排查
================================================================
1. 屏幕全黑
   先查背光（PB5 高电平点亮）：若强光斜照能看到淡淡图像 -> 背光电平反了，把
   pinmap.h 的 LCD_BL_ON / LCD_BL_OFF 对调；再查 P10/背光跳线是否插好，并拔掉
   摄像头再上电试。LCD 初始化失败会进 Error_Handler 死循环，看调试器 PC 即知。
2. 花屏 / 图像错位 / 滚动
   第一嫌疑：面板时序宏（pinmap.h 的 HSW/HBP/HFP/VSW/VBP/VFP）与 bsp_lcd.c 的
   四位极性；第二嫌疑：SDRAM（上电自检失败会在屏上打“SDRAM 自检失败”），
   帧率异常时还要核 PLLSAI 分频。
3. 摄像头无图 / 初始化失败
   确认插在 P6、方向对、断电插拔。ERR_SCCB 查 PB3/PB4 的 4.7K 上拉与 PA15 复位；
   ERR_ID（ID 不是 0x5640）说明模块不对或复位时序有问题。偏色改
   CFG_CAM_BYTE_SWAP=1；撕裂/错位查 DMA 长度（应为 38400 字）与取帧前清 OVRRI。
4. 汉字显示成方块 / 空白
   字库缺字。改完 config.h 或 app.c 的字符串后【直接重新编译】，构建会自动重跑
   tools/gen_font.py；机器没装 Python/Pillow 时这步会静默失败并沿用旧字库，
   手工执行 py tools\gen_font.py Inc\lcdfont.h tools\ui_strings.txt .
5. RV1 读数悬空 / 一直是 0 或 3.3 V
   最常见是 P10 跳线帽没插（拔掉后 PA5 完全独立，读到的是悬空电平）。PA5 必须是
   模拟输入且【不能开上下拉】。量程只有 0~3.3 V，接 5 V 会打坏 ADC 输入。
6. 编译报错
   "arm-none-eabi-gcc: not found" 是工具链没装或不在 PATH。字库那一步报错不会中断
   构建（Makefile 里命令前有 "-"），只是新字会缺，可 make clean all 重来。
   binutils >= 2.39 的 RWX 段警告已被 -Wl,--no-warn-rwx-segments 抑制。
7. 下载 / 调试：本机用正点原子 DAP（CMSIS-DAP）而非 ST-LINK，CubeIDE 探头选
   OpenOCD + CMSIS-DAP 或直接双击 flash.bat；摄像头占用了 PB3/PB4/PA15（JTAG 脚），
   所以调试只能用 SWD，不能用 JTAG。
