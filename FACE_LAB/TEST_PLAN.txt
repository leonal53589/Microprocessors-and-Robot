================================================================
 FACE_LAB 验收步骤与记录表 —— 人脸录入与识别（实验四）
================================================================
板卡：正点原子阿波罗 V2 STM32F429（STM32F429IGTx）+ DNF429-EB 实验箱
固件：build/FACE_LAB.elf（make all 产生，flash.bat 烧录）
外接：7 寸 800x480 RGB 屏（RGBLCD 接口）+ ATK-OV5640（P6 摄像头接口）
板载：W25Q256 SPI NOR Flash（32MB，SPI5：PF6~PF9，人脸库持久化）
      W9825G6KH SDRAM（32MB，帧缓冲/人脸库/特征/PCA 模型）
【接线】不需要杜邦线：屏接 RGBLCD、摄像头插 P6、Flash 与 SDRAM 都是板载。
        上电前确认 BOOT0=BOOT1=0、DAP 选 SWD 模式。详见 WIRING.txt。
【按键】K2 切模式（录入 -> 识别 -> 统计 -> 信息 -> 录入）
        录入：UP 选人 1~5；K0 拍照存一张；K1 删掉该人最后一张
        识别：UP 选真值（1~5 或 非库内人员）；K0 拍照并跑完四种方式；K1 切方式
        结果：UP 换"以哪个方式为准"（不重拍，用已算好的距离重判）；K0 再拍；K1 回预览
        统计：UP 切数据集（验证集 / 最终测试集）；K0 用验证集标定阈值；K1 清空统计
        信息：UP 清空验证集缓存；K0 清空整个图库；K1 重建模型
【双色灯】通过 绿(PB0)常亮/红(PB1)灭；不通过 红常亮/绿灭（低电平点亮）。
          灯跟随"当前选中方式"的判定。
【阈值】MSE 1200.0 / LBP 6.0 / COLOR 0.35 / PCA 2500.0（Inc/config.h 的起点值）。
        实验要求必须用【验证样本】标定后再用，最终测试样本只用一次。
----------------------------------------------------------------
 验收项 1 · 上电自检与图库载入
----------------------------------------------------------------
操作：1) 断电插好屏与摄像头，确认 BOOT0=BOOT1=0、DAP 为 SWD；
      2) 合上电源开关 K1，从标题开始顺序观察屏幕上的自检信息；
      3) 看右侧状态栏是否显示"预览 xx fps"与图库张数；
      4) 断电再上电，看是否自动载入上次录入的人脸
期望现象：屏幕依次显示 标题 -> SDRAM 自检结果 -> NOR Flash 状态
          （"Flash 正常，已载入图库" 或 "Flash 正常，图库为空"）
          -> 进入【录入模式】实时预览，侧栏提示 "K0拍照录入 K2换模式"
判定：
  [ ] 标题与副标题正确（实验四、微处理器与机器人）
  [ ] SDRAM 自检通过（失败会停在该提示上，不会进入界面）
  [ ] Flash 状态提示与实际相符（有图库/图库为空）
  [ ] 预览能出图，画面实时（手在镜头前晃动有响应）
  [ ] 侧栏显示实时帧率与图库总张数
  [ ] 断电重启后图库张数与断电前一致（持久化生效）
记录：首次出图耗时 ______ s   帧率 ______ fps   图库 ______ 张
      是否偏色（偏色则把 config.h 的 CFG_CAM_BYTE_SWAP 改成 1）：______
----------------------------------------------------------------
 验收项 2 · 人脸录入（含画质门限与槽位管理）
----------------------------------------------------------------
操作：1) UP 选到 1 号，K0 连拍 5~6 张（人脸填满取景框、正对镜头）；
      2) 故意用手遮住镜头 / 对着强光拍一张，看是否拒绝保存；
      3) 把人脸移出取景框一半再拍一张；
      4) 按 K1 删掉最后一张，再补拍一张；
      5) 继续把 2~5 号都录满 5 张
期望现象：每张成功保存都提示"已写入Flash并可断电保持"（Flash 不可用时提示
          "已存内存(Flash不可用)"）；侧栏"已录 x/6"随之增加；
          画质不合格时提示 太暗/太亮/未对准 并【不保存】；
          槽位满（6 张）后再按 K0 提示"该人员已满6张，先删再拍"
判定：
  [ ] 5 个人都能选中（UP 循环），侧栏人员号与已录张数同步变化
  [ ] 每人至少能录满 5 张，且张张都有明确的保存成功提示
  [ ] 太暗 / 太亮 / 未对准 三种情况均被拒绝保存，并给出对应提示
  [ ] 被拒绝时图库张数【没有】增加（没有把坏图存进去）
  [ ] K1 删除后张数减少，且删除的那张确实不再参与识别
  [ ] 槽位满时给出提示，不会覆盖旧图
记录：每人实际录入张数 1:___ 2:___ 3:___ 4:___ 5:___
      画质被拒次数：太暗 ___ 太亮 ___ 未对准 ___
----------------------------------------------------------------
 验收项 3 · 断电保持与记录完整性
----------------------------------------------------------------
操作：1) 录满图库后，把电源开关 K1 断开 5 秒再上电；
      2) 看启动时是否提示"Flash 正常，已载入图库"，张数是否一致；
      3) 在识别模式下对同一个人各拍一次，比较"断电前 / 断电后"的识别结果；
      4) 进信息界面查看 NOR Flash 的 JEDEC ID 与容量
期望现象：断电后图库仍在（记录写在 Flash 的独立数据区，从 0x01000000 起占 1MiB），
          逐条读回并做 CRC32 校验：坏掉的那一条不会被载入（张数会少）；
          器件 ID 应为 0xEF4019（W25Q256），容量 32MB
判定：
  [ ] 断电前后图库张数完全一致（每人张数也一致）
  [ ] 断电前后同一张脸的识别结果与距离基本一致（说明载入的是同一批图）
  [ ] 信息界面 JEDEC ID = 0xEF4019、容量 = 32MB
  [ ] 屏上没有出现"退化为仅内存图库"之类的降级提示
  [ ] 若出现降级提示：确认是"无应答 / ID 不符 / 容量不足"中的哪一种并记录
记录：断电前 ______ 张 -> 断电后 ______ 张
      JEDEC ID ________   容量 ______ MB   是否有降级提示：______
----------------------------------------------------------------
 验收项 4 · 四种识别方式与开放集判定
----------------------------------------------------------------
操作：1) 识别模式：UP 把真值设成"1 号"（本次要识别的人）；
      2) K0 拍照，屏幕进入结果界面，逐行看四种方式；
      3) 按 UP 换"以哪个方式为准"，观察大字判定与双色灯是否跟着变；
      4) 回预览，K1 切换方式（MSE/LBP/COLOR/PCA），确认侧栏"算法"跟着变；
      5) 换一个人重复；再把真值设成"非库内人员"，让没录入过的同学入镜拍一张
期望现象：结果界面显示：左侧抓拍人脸 4 倍放大 + 画质 + 亮度；
          右侧四行 = 方式 / 距离 / 阈值 / 判定（通过 或 不通过）/ 预测人员；
          当前选中方式那一行高亮，底部大字判定与双色灯跟随它；
          开放集规则：最近邻距离 <= 该方式的阈值 才判"通过"，
          否则即使最近邻属于某个已录入的人，也判"不通过"
判定：
  [ ] 四种方式都能给出距离、阈值与判定（样本不足时会显示"不可用"）
  [ ] 已录入者本人拍照：四种方式的距离都明显小于非本人的距离
  [ ] 把真值设成"非库内人员"时，未录入者的距离明显大于已录入者
  [ ] 选中方式切换后，大字判定与双色灯【立刻】跟着改变（不需要重拍）
  [ ] 结果界面显示本次识别总耗时（四种方式合计，ms）
  [ ] 绿/红灯与判定一致：通过 -> 绿灯亮红灯灭；不通过 -> 红灯亮绿灯灭
记录表（距离，越小越像）：
    被测对象       MSE       LBP      COLOR      PCA      是否正确
    ------------  --------  -------  ---------  --------  --------
    1 号本人      ________  _______  _________  ________  ________
    2 号本人      ________  _______  _________  ________  ________
    非库内人员    ________  _______  _________  ________  ________
  本次识别总耗时 ______ ms

 验收项 5 · 阈值标定与统计（验证集 / 最终测试集分开）
----------------------------------------------------------------
操作：1)【先做验证集】识别模式下把真值设对，每人拍 2 张、再让 2~3 位
         未录入者各拍 2 张（真值设"非库内人员"）——每次抓拍都会自动进缓存；
      2) K2 切到统计界面，UP 确认数据集是"验证集（用来标定阈值）"；
      3) 看"验证样本缓存 x/12"，然后按 K0 用验证集标定当前方式的阈值；
      4) 观察阈值数值变化与"已标定"标记，再换另一种方式重复标定；
      5)【再做测试集】UP 切到"最终测试集（只用一次）"，按要求各拍一遍，
         看统计表里的三个率；最后把数据记下来
期望现象：标定成功后阈值从起点值变成一个"落在库内距离与库外距离之间"的值，
          并标记"已标定"；样本不够（缺库内或库外）时会提示"验证样本需含
          库内与库外两类"；统计表按方式列出 库内次数 / 正确通过率 / 误拒率 /
          库外次数 / 误通过率；数据集切换后三率是各自独立统计的
判定：
  [ ] 验证集的每次抓拍都会让"验证样本缓存"增加（测试集的抓拍不入缓存）
  [ ] K0 标定后阈值发生变化，且标记为"已标定"
  [ ] 标定后的阈值介于"库内距离"与"库外距离"之间（与验收项 4 的记录对照）
  [ ] 库内 / 库外两类样本缺任一类时，标定被拒绝并给出提示
  [ ] 切到"最终测试集"后，统计数字从 0 开始独立计数
  [ ] 三种率都能显示（分母为 0 时显示 "--"）
记录表：
    方式    标定前阈值  标定后阈值  正确通过率  误拒率  误通过率
    ------  ----------  ----------  ----------  ------  --------
    MSE     __________  __________  __________  ______  ________
    LBP     __________  __________  __________  ______  ________
    COLOR   __________  __________  __________  ______  ________
    PCA     __________  __________  __________  ______  ________
  ★ 注意：阈值标定结果只保存在内存里，重新上电会回到 config.h 的起点值；
          最终测试集只能用一次，不要反复调参后重测。

 验收项 6 · 信息界面与模型状态
----------------------------------------------------------------
操作：1) K2 切到信息界面，逐项核对；
      2) 按 K1 重建模型，看"上次建模耗时"与模型状态；
      3) 按 UP 清空验证集缓存，看统计界面的缓存数归零；
      4) （谨慎）按 K0 清空图库，确认图库清零、模型变为不可用
期望现象：显示 SDRAM 自检与刷新计数、NOR Flash 的 JEDEC ID 与容量、
          每人已录张数、训练样本数、PCA 主成分 k=16、PCA 训练耗时、
          四种方式模型状态（就绪/不可用），以及断电保持是否开启的说明
判定：
  [ ] SDRAM 自检显示"通过"，刷新计数在变化
  [ ] 每人已录张数与实际录入一致，训练样本数 = 图库总张数
  [ ] 四种方式模型状态与是否录满 5 人 × 5 张相符
  [ ] PCA 训练耗时能显示（毫秒级），重建模型后数值会更新
  [ ] 清空验证集缓存后，统计界面显示的缓存数归零
  [ ] （清空图库后）模型状态变为不可用，识别界面显示"无模型"而不是"通过"
记录：训练样本 ______    PCA 训练耗时 ______ ms
      模型状态 MSE ___ LBP ___ COLOR ___ PCA ___（就绪/不可用）

 验收项 7 · 接线与供电安全（这一项是"查"，不是"测"）
----------------------------------------------------------------
  1) 供电：DC_IN 接 6~15V（12V/1A 适配器或实验箱 DP100），总开关 K1 按下，
          电源指示灯亮；不用仿真器给开发板供电
  2) 启动：BOOT0 = BOOT1 = 0（两颗跳线帽都接 GND），从 Flash 启动
  3) 调试：板上 20 针 JTAG/SWD 座接实验箱 DAP，【必须选 SWD 模式】
          （摄像头占用 PB3/PB4/PA15，它们同时是 JTAG 的 JTDO/NJTRST/JTDI）
  4) 屏与摄像头：都插到底、方向正确（屏按丝印缺口、摄像头靠 3V3/GND 那端起插），
          每次插拔都在断电状态
  5) 触摸：上电后板子无异常发热、无异味，SDRAM/Flash 区域不烫手
判定：
  [ ] 供电电压在 DC 6~15V 范围内，K1 与电源指示灯工作正常
  [ ] BOOT0/BOOT1 均为 0
  [ ] 调试器是 SWD 模式（不是 JTAG）
  [ ] 屏、摄像头都插到底且方向正确；插拔均在断电状态下进行
  [ ] 上电无异常发热

 附一 · 参数速查
================================================================
时钟：HSE 25 MHz -> PLLM=25 / PLLN=360 / PLLP=2 -> SYSCLK 180 MHz；HCLK 180 /
      APB1 45 / APB2 90 MHz；SDRAM SDCLK = HCLK/2 = 90 MHz；LTDC 像素时钟 30 MHz
LTDC：HSW 48 / HBP 88 / HFP 40 -> 行 976；VSW 3 / VBP 32 / VFP 13 -> 场 528
      帧率 = 30 MHz / (976 x 528) = 58.2 Hz；RGB565；帧缓冲 750 KiB @ 0xC0000000
SDRAM：W9825G6KH-6 32 MB，SDCLK 90 MHz，CAS=3
      刷新计数器 = (64ms / 8192 行) x 90MHz - 20 = 683
DMA：DMA2_Stream1_Channel1，P2M，Word/Word，Length = 320x240x2/4 = 38400 字
     （单位是"字"不是字节）；帧超时 400 ms，连续 3 次失败判"无信号"
SPI5（W25Q256）：AF5，APB2/4 = 22.5 MHz，模式 0，软件 NSS（PF6 普通推挽输出）；
     容量 32 MB > 16 MB，必须用 4 字节地址模式（上电发 0xB7）
SDRAM 分区（都在 0xC0000000 起）：
     LCD 帧缓冲      +0x000000  750 KiB
     摄像头缓冲      +0x100000  150 KiB x2
     人脸图库        +0x160000  30 条 x 6928 B = 203 KiB（预留 256 KiB）
     特征区          +0x1A0000  LBP 240 KiB + 颜色 30 KiB + 验证缓存 81 KiB（预留 512 KiB）
     算法工作区      +0x220000  PCA 模型约 229 KiB + 训练样本 68 KiB（预留 512 KiB）
     SDRAM 自检区    +0x1000000（16 MiB 处，远离以上所有分配）
人脸与特征：48x48 = 2304 像素（RGB565 + 灰度）；LBP = 4x4 分区 x 256 桶 = 4096 维；
      颜色直方图 = 8x8x8 = 512 桶；PCA 主成分 k = 16（且 k <= 样本数-1）
取景框：QVGA(320x240) 里的 (80,30) 起 160x160，裁剪后缩放到 48x48
画质门限：灰度均值 50~205，对比度 (P95-P5) >= 28，不满足则提示重拍
算法阈值（起点值，需标定）：MSE 1200.0 / LBP 6.0 / COLOR 0.35 / PCA 2500.0
人员与槽位：5 人 x 每人 6 槽（最少 5 张训练图）；图库最多 30 条
Flash 记录格式：每条占 2 个 4KB 扇区；头 12 B（magic/版本/人员/槽位/时刻）
      + 4608 B RGB565 + 2304 B 灰度 + 4 B CRC32；库头在第 1 个扇区
任务周期：按键 10 ms / 界面 200 ms / 摄像头帧超时 400 ms / 抓拍超时 800 ms
引脚：屏 = LTDC(AF14) + 背光 PB5；摄像头 = DCMI(AF13) + SCCB PB4/PB3 + RST PA15；
      Flash = SPI5 PF6(CS)/PF7(SCK)/PF8(MISO)/PF9(MOSI)；
      绿灯 PB0；红灯 PB1；按键 K0 PH3 / K1 PH2 / K2 PC13 / UP PA0

 附二 · 常见问题排查
================================================================
1. 屏幕全黑
   先查背光（PB5 高电平点亮）：若强光斜照能看到淡淡图像 -> 背光电平反了，把
   pinmap.h 的 LCD_BL_ON / LCD_BL_OFF 对调。LCD 初始化失败会进 Error_Handler
   死循环（屏上无提示），看调试器 PC 即知。
2. 花屏 / 图像错位 / 滚动
   第一嫌疑：面板时序宏（pinmap.h 的 HSW/HBP/HFP/VSW/VBP/VFP）与 bsp_lcd.c 的
   四位极性；第二嫌疑：SDRAM（自检失败会在屏上打"SDRAM 自检失败，请检查 FMC"），
   帧率异常时再核 PLLSAI 分频。
3. Flash 无应答 / 器件 ID 不符 / 退化为仅内存图库
   屏上会明确提示是哪一种。查 PF6~PF9 是否被其它代码改过（这四根线板上已连
   W25Q256）、以及是否误改成普通 IO；ID 读不到时先确认 SPI5 波特率前提：
   APB2 = 90 MHz -> 22.5 MHz。降级状态下图库只在内存，断电后会丢失。
4. 摄像头无图 / 初始化失败
   确认插在 P6、方向对、断电插拔。按 K1 可重新初始化。偏色改
   CFG_CAM_BYTE_SWAP=1；撕裂/错位查 DMA 长度（应为 38400 字）与取帧前清 OVRRI。
5. 识别总是"不通过"
   先看结果界面里的"距离 / 阈值"：距离明显大于阈值说明特征差异太大——
   检查录入与识别是否用同一距离与姿态（本实验不做人脸检测，靠人工对准），
   再考虑用验证集重新标定阈值（统计界面按 K0）。
6. 断电后录入的人脸没了
   看启动时是否提示"退化为仅内存图库"。若确实降级（Flash 无应答/ID 不符），
   则图库只在内存中；否则检查录入时是否提示过"Flash写入失败"。
7. 编译报错
   "arm-none-eabi-gcc: not found" 是工具链没装或不在 PATH。字库那一步报错不会
   中断构建（Makefile 里命令前有 "-"），只是新字会缺，可 make clean all 重来。
   binutils >= 2.39 的 RWX 段警告已被 -Wl,--no-warn-rwx-segments 抑制。
8. 下载 / 调试
   本机用正点原子 DAP（CMSIS-DAP）而非 ST-LINK：CubeIDE 探头选 OpenOCD +
   CMSIS-DAP，或直接双击 flash.bat。摄像头占用了 PB3/PB4/PA15（JTAG 脚），
   所以调试只能用 SWD，不能用 JTAG。
