================================================================
 TIMER_LAB 验收步骤与记录表
================================================================
板卡：正点原子阿波罗 V2 STM32F429 + DNF429-EB 实验箱
固件：build/TIMER_LAB.elf（make all 产生，flash.bat 烧录）

【统一接线规则】
    所有外接 LED 都是【低电平点亮】：
        正极（长脚）-- 1K 限流电阻 -- 3.3V
        负极（短脚）-- 对应引脚
    依据：硬件手册 LED 原理图
        VCC3.3 --[R62 510R]-- DS0(红) -- PB1
        VCC3.3 --[R65 510R]-- DS1(绿) -- PB0
    LED 由 VCC 经电阻、经 LED 到 MCU 引脚（MCU 灌电流），故低电平点亮，
    且没有三极管，引脚可直接做 PWM 调光。

【按键约定（全部板载，无需接线）】
    UP  (PA0)  切换 / 翻页 / 换模式 / 改 N
    K0  (PH3)  确认 / 启动 / 反应按键
    K1  (PH2)  返回主菜单
    K2  (PC13) 实验五「刹车确认恢复」
    蜂鸣器：每次按键"滴"一声；抢跑、刹车有专门提示音

【引脚在哪个排针上找】
    P5 排针（1x16，按顺序引出 FMC_D0~D15）：
        1脚 = D0  = PD14      7脚 = D6  = PE9
        8脚 = D7  = PE10     13脚 = D12 = PE15
    P2 / P3 排针（各 2x22）：PB0 / PB1 / PB5 在这些排针上，按丝印找
    P6 排针（2x9，丝印 OLED/摄像头接口）：OLED 模块直接插这里

 实验一 · OLED 基础显示与统一显示接口
================================================================
接线：无。OLED 模块直接插板上 P6，靠一侧插，剩下 2 个孔悬空。

操作：上电 -> 看菜单 -> UP 翻页 -> K0 进入第一项

期望：
    定时器实验
    >1 OLED显示
     2 反应速度
     3 三色呼吸
   （UP 翻页后能看到第 4、5 项）

    进入后：
    定时器实验
    姓名 张三          <- Inc/config.h 里可改
    学号 20260001
    计数 1             <- 每秒 +1

判定：
    [ ] 菜单正常显示，中英文都不乱码
    [ ] UP 能翻页，K0 能进入，K1 能返回
    [ ] 计数每秒递增
    [ ] 屏幕不黑、不花

若全黑 -> 模块不是 8080 并口模式，命令行走：
        make clean all IFMODE=SPI        (4 线 SPI)
        make clean all IFMODE=IIC        (IIC)
    然后 flash.bat，再试。

================================================================
 实验二 · 随机反应速度测试器（TIM6 1ms 基准）
================================================================
接线：1 只 LED -> PE10（P5 排针 8 脚）

操作与期望：
  1) K0 开始 -> 屏幕显示"请等待 / 不要抢跑"，LED 灭
  2) 随机等 2~5 秒后，LED 亮起，屏幕显示"按K0！"
  3) 立刻按 K0 -> 显示"本次 xxx ms"，并记录最好成绩
  4) 再玩几次，最好成绩会更新

抢跑测试：
  K0 开始后，在 LED 亮之前按任意键
        期望：显示"抢跑！请等提示灯"，LED 保持灭

判定：
    [ ] 等待时间随机（每次不一样，2~5 秒）
    [ ] LED 亮起与计时同时
    [ ] 反应时间量级合理（正常人 200~400ms）
    [ ] 抢跑能识别
    [ ] 最好成绩会更新
    [ ] 长按 K0 不会重复触发

记录：
    第1次 ______ ms    第2次 ______ ms    第3次 ______ ms
    最好成绩 ______ ms

================================================================
 实验三 · 三色流水呼吸灯（TIM3 三路 PWM，1kHz）
================================================================
接线：3 只 LED（蓝/绿/红）-> PB5 / PB0 / PB1
      注意：PB0/PB1 同时接着板载 DS1(绿) / DS0(红)，会一起亮，属正常

操作与期望：
    UP 依次切换三种模式，K0 暂停/继续
      [同步呼吸] 三路同相位，一起渐亮渐暗
      [三色流水] 三路相差 120 度，亮暗依次起伏
      [警灯闪烁] 红蓝交替快闪

判定：
    [ ] 三路都能独立调亮度（不是只有亮/灭两态）
    [ ] 呼吸平滑，没有明显闪烁（说明真的是 1kHz PWM）
    [ ] 三种模式都能切换
    [ ] K0 能暂停、再按能继续

若三路都只是"闪"而不是"呼吸" -> 说明 PWM 频率不对（应为 1kHz）

================================================================
 实验四 · 频率与占空比自测仪（TIM4 输出 + TIM3 输入捕获）
================================================================
接线：1 根杜邦线把 PD14 和 PB5 直接连起来（P5 排针 1 脚 <-> P2/P3 上的 PB5）
      安全说明：PB5 此时是 TIM3_CH2 复用输入，不是推挽输出，
                所以两个引脚直连不会对拉。

操作与期望：
    UP 依次切换三个测试点，屏幕显示三行：
        设 100Hz   25.0
        测 100Hz   25.0
        误 0.0%

    测试点：100Hz/25%、1kHz/50%、10kHz/75%

判定：
    [ ] 三个点的"测"值与"设"值接近
    [ ] 相对误差在预期范围内：
            100Hz  : 量化误差约 0.01%
            1kHz   : 约 0.1%
            10kHz  : 约 1%      <- 越到量程上端误差越大，这是 1us 计数的固有限制
    [ ] 把跳线拔掉后 150ms 内显示"测 无信号 / 请接跳线"
    [ ] 拔线后不会继续显示旧的测量值

记录：
    100Hz/25%   设定 100 / 25.0   测量 ______ / ______   误差 ______
    1kHz/50%    设定 1000 / 50.0  测量 ______ / ______   误差 ______
    10kHz/75%   设定 10000 / 75.0 测量 ______ / ______   误差 ______

================================================================
 实验五 · N 次闪光与硬件急停（TIM1 RCR+OPM+MOE+BKIN）
================================================================
接线：1 只 LED -> PE9（P5 排针 7 脚）
      1 只直插按键：一端接 PE15（P5 排针 13 脚），另一端接 GND
      说明：PE15 内部上拉，不按为高电平 = 刹车无效；按下接地 = 触发刹车

操作与期望：
  1) UP 改 N（1~9 循环），屏幕显示"次数 N=x"
  2) K0 启动 -> LED 精确闪 N 次后自动停止，屏幕显示"已停止"
  3) 运行中按下急停按键
        期望：LED 立刻灭（硬件异步清 MOE），屏幕显示"已刹车 K2确认"
  4) 松开急停按键
        期望：不会自动恢复（AOE=0），仍是"已刹车"
  5) 按 K2 确认
        期望：清刹车标志、重新使能输出，回到"待机"

判定：
    [ ] N=1、N=5、N=9 都准确闪对应次数（数一下）
    [ ] 发完自动停，不会一直闪
    [ ] 急停响应是"立刻"的（不是等一个周期）
    [ ] 松开急停不会自动恢复
    [ ] 必须按 K2 才能恢复
    [ ] 刹车后未确认时，按 K0 拒绝启动

记录：
    N=1 实际闪了 ____ 次
    N=5 实际闪了 ____ 次
    N=9 实际闪了 ____ 次
    急停是否立刻生效：____
    松开是否自动恢复：____

 附：定时器参数速查（详细推导见 Readme 第三节）
================================================================
    TIM6  90MHz  PSC=89  ARR=999   -> 1000 Hz (1ms 基准)
    TIM3  90MHz  PSC=89  ARR=999   -> 1000 Hz (三色 PWM)
    TIM1 180MHz  PSC=179 ARR=999   -> 1000 Hz,  RCR = N-1
    TIM4  90MHz  100Hz ->PSC=89 ARR=9999   1kHz ->PSC=8 ARR=9999
                 10kHz ->PSC=0  ARR=8999
    捕获  1MHz 分辨率，最低可测 15.259 Hz

    定时器时钟不等于 CPU 主频：
        APB1 = 45MHz  -> APB1 定时器 = 90MHz  (TIM2~7, TIM12~14)
        APB2 = 90MHz  -> APB2 定时器 = 180MHz (TIM1, TIM8~11)

================================================================
 常见问题
================================================================
1. 屏幕全黑
   先确认 OLED 模块插到底、方向对；再试换接口模式
   （make clean all IFMODE=SPI 或 =IIC，然后 flash.bat）

2. 界面上出现 "?"
   字库里缺这个字。改完 config.h 里的姓名后直接重新编译即可
   （构建时会自动重生字库）；若那台机器没装 Python，手工跑：
       py tools\gen_font.py Inc\oledfont.h tools\ui_strings.txt .

3. 下载报 "No ST-LINK detected"
   本机用的是正点原子 DAP（CMSIS-DAP），不是 ST-LINK。
   CubeIDE 里调试探头要选 OpenOCD + CMSIS-DAP；
   或者直接双击 flash.bat。

4. 下载报 "CMSIS-DAP command mismatch"
   IDE 上次失败的调试留下了 openocd 进程占着 DAP。
   flash.bat 里已经加了 taskkill，或者手工：
       taskkill /f /im openocd.exe

5. 实验三/四 与板载 DS0/DS1、7 寸屏背光(PB5) 有共用关系
   - PB0/PB1 就是板载 DS0/DS1，做 RGB 时它们会一起变化，正常
   - PB5 是 LCD_BL，接了 7 寸屏的话背光会被一起驱动，不影响功能
