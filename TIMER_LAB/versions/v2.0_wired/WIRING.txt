 1. 通用规则：外接 LED 怎么接
----------------------------------------------------------------
    图：tools/wiring/01_led_basic.png

        3.3V
         │
       [1K]          限流电阻，必须串
         │
        ▼ LED        正极（长脚）朝上
         │           负极（短脚）朝下
      MCU 引脚       输出低电平 = 点亮

    规则：正极（长脚）-- 1K 电阻 -- 3.3V，负极（短脚）-- MCU 引脚

    ★ 为什么是低电平点亮？依据是《阿波罗V2 硬件参考手册》的 LED 原理图：
          VCC3.3 --[R62 510R]-- DS0(红) -- PB1
          VCC3.3 --[R65 510R]-- DS1(绿) -- PB0
      电流从 VCC 经电阻、经 LED 流进 MCU 引脚（MCU 灌电流），所以低电平点亮。
      而且 LED 没有经过三极管，引脚可以直接做 PWM 调光，亮度 = 1 - 占空比。

 2. 逐个实验的接线
----------------------------------------------------------------
【实验一 · OLED】不用接线
    OLED 模块直接插板上 P6（丝印 OLED/摄像头接口，2x9 黄色排针）
    - 从【3V3 / GND】那一端开始插，让这两个供电脚被模块盖住
    - 2x8 的模块插 2x9 的排针，另一端会空出 2 个孔，这是正常的

【实验二 · 反应速度】不用接线
    提示灯就是板载的 DS0（PB1，红色），程序里同时并联驱动了 PE10，
    想外接一只更醒目的 LED 就接 PE10（可选）。

【实验三 · 三色呼吸】
    图：tools/wiring/03_exp3_rgb.png
    - 红色 LED = 板载 DS0（PB1）  不用接
    - 绿色 LED = 板载 DS1（PB0）  不用接
    - 蓝色 LED → 外接到 PB5        ★ 只需接这一只
    三只灯都串 1K 电阻、低电平点亮。

【实验四 · 频率占空比自测仪】
    图：tools/wiring/04_exp4_jumper.png
    - 用一根杜邦线把 PD14（P5 排针 1 脚）和 PB5 直接短接
    - 安全：PB5 在这个模式里是 TIM3_CH2 的【复用输入】，不是推挽输出，
            所以两个引脚直连不会对拉
    - 拔掉这根线，程序 150ms 内就显示「测 无信号」

【实验五 · N 次闪光与硬件急停】
    图：tools/wiring/05_exp5_flash_bkin.png
    - 闪光 LED → PE9（P5 排针 7 脚），串 1K，低电平点亮
    - 急停按键 → 一端接 PE15（P5 排针 13 脚），另一端接 GND
      （PE15 内部上拉，不按 = 高 = 刹车无效；按下接地 = 触发刹车）

----------------------------------------------------------------
 3. P5 排针在哪里
----------------------------------------------------------------
    图：tools/wiring/02_header_p5.png

    P5 是 1x16 的排针，按顺序引出 FMC_D0 ~ FMC_D15：
        1脚=PD14   7脚=PE9    8脚=PE10   13脚=PE15
    板上排针旁边有丝印，按丝印找即可。
    PB0 / PB1 / PB5 在 P2 / P3 引出排针上（各 2x22，共 86 个 IO）。

 4. ★★ 引脚是怎么推导出来的（这部分是方法，学会了自己就能排）★★
----------------------------------------------------------------
    核心思路：需求 → 外设 → 定时器 → 通道 → 候选引脚 → 排除冲突 → 排针

    第 1 步  把需求翻译成"要几个什么样的外设"
             例：三色呼吸灯 = 3 路独立可调亮度的 PWM，频率 1kHz

    第 2 步  从外设反查定时器（查《STM32F429 参考手册》定时器章节）
             STM32F429 的定时器分类：
               基本定时器   TIM6 / TIM7          无输出通道，只能做时间基准
               通用定时器   TIM2~TIM5 (各4通道)  TIM9(2) TIM10/11(1)
                            TIM12(2) TIM13/14(1)
               高级定时器   TIM1 / TIM8 (各4通道 + 互补输出 + 刹车输入 + 重复计数器)
             本实验要求"用通用定时器"，且要在同一个定时器上有 >= 3 个通道，
             所以 TIM2/TIM3/TIM4/TIM5 都满足。
             再考虑整体分配：TIM1 要留给实验五，TIM4 要留给实验四的输出，
             → 实验三选 TIM3

    第 3 步  从定时器通道反查候选引脚
             查《STM32F429 数据手册》的 Alternate function mapping 表：
               TIM3_CH2  →  PA7  /  PB5  /  PC7
               TIM3_CH3  →  PB0  /  PC8
               TIM3_CH4  →  PB1  /  PC9

    第 4 步  用《阿波罗V2 STM32F429开发板IO引脚分配表》逐个排除
             （这一步最关键，表里会写明每个 IO 接了板上什么外设）
               PC7 / PC8 / PC9  → 被 OLED 的 P6 接口占用        ✗
               PA7              → RMII_CRS_DV，接在以太网 PHY 的【输出】脚上，
                                  当推挽输出会和 PHY 对拉           ✗
               PB5              → LCD_BL，TFTLCD 背光控制脚。
                                  它是往屏里送的【输入】信号，不会对拉；
                                  不接屏时完全空闲                   ✓
               PB0              → 板载 DS1（绿色 LED）           ✓ 正好当绿灯
               PB1              → 板载 DS0（红色 LED）           ✓ 正好当红灯
             → 最终：TIM3_CH2 = PB5(蓝)   TIM3_CH3 = PB0(绿)   TIM3_CH4 = PB1(红)

    第 5 步  确认排针位置
             PB0 / PB1 / PB5 都在 P2 / P3 引出排针上，按板上丝印找。

    同样的方法走一遍其余三个：

     实验二（TIM6，1ms 基准）
        需求：1ms 时间基准，不需要引脚
        → 基本定时器 TIM6 没有输出通道，正好不占 IO

     实验四（TIM4 输出 + TIM3 捕获）
        需求：一路 PWM 输出 + 一路输入捕获，要接跳线
        输出侧：TIM4_CH3 → PB8 / PD14；PB8 被 OLED 占用 → 选 PD14
        捕获侧：TIM3_CH2 → PA7 / PB5 / PC7；PA7 被 PHY 占用、PC7 被 OLED 占用
                → 选 PB5（和实验三的蓝灯共用，两个模式互斥，不冲突）

     实验五（TIM1，N次闪光 + BKIN）
        需求：PWM 输出 + 硬件刹车输入
        CH1：PA8 / PA9 / PA10 / PA11 / PE9 / PE13
             PA8 被 OLED 占用、PA9/PA10 是串口1、PA11 是 USB/CAN
             PE13 和 PD14/PE9 一样是 FMC 数据线
             → 选 PE9（PE 组的 FMC 数据线未初始化时是高阻，可安全当普通 IO）
        BKIN：PA6 / PB12 / PE15
             PA6 被 OLED 的 PCLK 占用、PB12 是 IIC_INT/单总线
             → 选 PE15

    ★ 判断"某个 IO 能不能用"的三条经验：
      1) 看它接的是【输入型】外设（如 LCD_BL、FMC 数据线到 SDRAM 的 DQ）
         —— 外设不工作时通常高阻或高阻态输入，可以借用
      2) 看它接的是【输出型】外设（如以太网 PHY 的 CRS_DV）
         —— 不能当推挽输出，会和对方对拉
      3) 看时序敏感的外设（如 SDRAM 数据线）
         —— 现在没初始化 FMC，接的是高阻的 DQ，安全；
            但将来一旦做 LCD/SDRAM 实验，这些脚就会冲突

 6. 常见坑
----------------------------------------------------------------
  1) OLED 用了 13 个 IO，其中 PC6~PC9 正好是 TIM8_CH1~CH4，
     所以本工程的高级定时器实验只能用 TIM1，不能用 TIM8。
  2) PB3 / PB4 / PA15 被 OLED 占用（它们是 JTAG 的 JTDO/JTRST/JTDI），
     所以调试只能用 SWD 模式，不能用 JTAG —— 本工程全程用的就是 SWD。
  3) PE7~PE15 / PD0 / PD1 / PD8~PD10 / PC0~PC3 / PF 全部是 FMC 总线脚。
     不用 FMC 时它们是安全的（接的是 SDRAM 的 DQ，高阻）；
     但将来做 LCD 或 SDRAM 实验时，本工程用的 PE9/PE10/PE15/PD14 就会冲突，
     那时候需要重新规划到 P2/P3 排针上没用到的脚。
  4) 实验三和实验四都用到 PB5，但它们是互斥的菜单模式，不会同时工作。
     程序在切换模式时会重新配置 PB5 的方向（输出 PWM / 输入捕获）。
  5) 外接 LED 必须串 1K 限流电阻；PWM 输出脚和捕获脚跳接前，
     确认捕获端配置成了【复用输入】而不是推挽输出（本工程已保证）。
